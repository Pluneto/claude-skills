# No tracker doc

Read by to-tickets, wayfinder and build-this when the repo has no `docs/agents/issue-tracker.md`: nothing says where tickets go, so this run decides. Each of those skills carries an identical copy of this file (`scripts/validate` keeps them in sync; edit all three).

1. **Pick the tracker.** build-this skips the question: the tickets it was given (a folder or an issue list) say where they live. Otherwise ask once: GitHub Issues or local files under `plans/`. Recommend local when `plans/*/tickets/` already holds tickets, else GitHub when `git remote -v` points at GitHub, else local. Add one line: `/setup:setup-pluneto-skills` records the choice (and creates the labels), so later runs skip this question. Done when the tracker is known.
2. **Use these defaults for this run.**
   - **GitHub**: check the target with `gh repo view --json nameWithOwner` (stop if it fails; in a fork, confirm the repo with the user). Labels: `ready-for-agent` and `ready-for-human` for to-tickets tickets, `wayfinder:map` and `wayfinder:<type>` for wayfinder, `in-progress` for claims. Before the first write, run `gh label list --json name --limit 1000` and create each missing label with `gh label create "<name>"` (no `--force`; compare names ignoring case). Blocking: `gh issue create --blocked-by <n>,<n>` (gh 2.94+), else a `Blocked by: #<n>` line at the top of the body. Sub-issues: `gh issue create --parent <n>`.
   - **GitHub claim**: comment `claimed by <branch>` and note the comment URL gh prints, add the `in-progress` label, wait 10 s, then re-read the comments (`gh issue view <n> --json comments`). Counting only comments whose `authorAssociation` is OWNER, MEMBER or COLLABORATOR, the earliest `claimed by` comment since the last `released:` comment wins; when it isn't yours, stop and change nothing. **Release**: comment `released: <reason>` (`released: done in #<pr>` after a merge) and remove the label. Finish a ticket with a PR whose body says `Fixes #<n>`, wait for green CI, and merge only when the user said so.
   - **Local**: `plans/<slug>/`, with `map.md` for a wayfinder map and one file per ticket at `tickets/NN-<slug>.md`, numbered from 01 blockers first. Each ticket starts with `Who: agent|human` (to-tickets), `Type: research|prototype|interview|task` (wayfinder), `Blocked by: NN, NN` (or `None`) and `Status: open|claimed|resolved`; the answer goes under `## Answer`. Claim: set `Status: claimed` before any work; release: `resolved` when done, `open` when abandoned.
